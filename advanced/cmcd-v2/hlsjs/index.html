DoveRunner - HLS.js CMCD v2 Sample

This sample demonstrates CMCD v2 event mode data transmission with DRM support using HLS.js player.

Custom data is added via window.fetch override because HLS.js does not provide a built-in network interceptor API.

Please check the DoveRunner and HLS.js docs sites for more information.

DoveRunner Docs ↗ Visit HLS.js Docs ↗

Features:

  • ✅ CMCD v2 Event Mode - JSON Batch reporting to Loading...
  • ✅ Batch Configuration:
    • Batch Size: 100 events
    • Batch Timer: 30 seconds
    • Time Interval: 10 seconds
  • ✅ Custom data transmission via JSON body:
    • com.doverunner.player.device-type
    • com.doverunner.player.browser-type
    • com.doverunner.drm-auth-data
    • com.doverunner.drm-license-requested-count
    • com.doverunner.drm-license-latency-N (dynamic per request)
    • com.doverunner.drm-error-code-N (dynamic per request)
    • com.doverunner.drm-server-response-code-N (dynamic per request)
