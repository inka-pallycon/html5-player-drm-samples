DoveRunner CSL License Renewal Samples

These samples demonstrate license renewal for Concurrent Stream Limiting (CSL) scenarios using various HTML5 players.

For accurate CSL scenario reproduction, the content license must have a Renewal Interval configured. For more details, please refer to the CSL Guide.

Note: Widevine license renewal is handled automatically by the CDM. Other DRMs (PlayReady, FairPlay) require manual license renewal implementation in the player.
